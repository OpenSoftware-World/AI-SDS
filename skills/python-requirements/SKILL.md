# Python projelerinde bağımlılık yönetimi için bilmen gerekenler.

* requirements.txt dosyası projenin kök dizininde bulunmalıdır.
* Projede kullanılan bağımlılıkları not al ve geliştiricinin bilgisayarında yüklü olan sürümler hangisiyse onları requirements.txt dosyasına yaz. (Örnek: Flask==0.3.0 şeklinde geliştirici o projeyi kodlarken hangi sürüm bulunuyorsa onu yaz.)
