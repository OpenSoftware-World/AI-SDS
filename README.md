# AI-SDS (AI Software Development System)

## What is this project?

These are sets of instructions designed to help individuals whether they are developing (or looking to develop) applications using the "vibe coding" approach with the aid of various AI-powered coding tools, or are developers seeking to leverage AI for specific tasks within their own projects use these AI tools with ease.

## The purpose of the project

It is the development of software using AI-powered coding tools, characterized by more systematic and accurate architectural decisions.

## What is my goal for this project?

To facilitate the work of developers and individuals looking to engage in software development by using AI-powered coding tools, while also establishing a system that encourages people to contribute to and choose this project.

## What is its value from my perspective?

A few months ago, I was someone who didn’t really embrace the use of AI in software development processes and, to some extent, I still feel that way. Nevertheless, I wanted to develop a project to address this challenge. My goal was to create sets of instructions that are more systematic and better aligned with software development workflows, helping AI models gain a deeper understanding of software development and, ultimately, leading to the creation of higher-quality software products.

## Which tools did I test on?

I can say that, so far, I have only conducted tests on "opencode," and I have begun to see better results than usual.

## Points to consider / potential risks

* Before you begin using these sets of instructions, please verify whether they align with your own development processes and meet your specific needs. If this project does not currently suit your workflow, you might consider contributing to its further development.
* You should not assume that these instructions will always yield 100% accurate results; I recommend verifying the output provided by the AI.
* You can also test these instructions across different AI models. Sharing your findings specifically which models produce the most accurate results would be a valuable contribution toward improving this repository together.

## What does it include?

Note: For the time being, the instruction set and custom commands to be added to this project will be in Turkish; however, I aim to make them available in other languages ​​as well, in a controlled manner, at a later stage.

* The `AGENTS.md` file, which defines systematic rules for coding agents.
* The `review.md` command, which allows you to examine an open-source project and identify its shortcomings.
* The `docs.md` command, which enables you to generate documentation for your project.

## How do I use it?

* If you are using a Linux distribution, navigate to the ".config/opencode" directory and copy the AGENTS.md file there.
* For custom commands, navigate to the ".config/opencode/commands" directory and copy your custom commands there.
